# Segurança

## Como relatar uma vulnerabilidade

Não publique detalhes sensíveis em uma issue aberta.

Use a opção **Report a vulnerability** na aba **Security** do repositório. Inclua:

- Uma descrição do problema.
- Passos para reproduzi-lo.
- O possível impacto.
- Uma sugestão de correção, se tiver.

Confirmaremos o recebimento e evitaremos divulgar detalhes antes da correção.
